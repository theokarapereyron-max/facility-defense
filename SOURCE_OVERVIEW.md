# Facility Defense — source publiée

Ce dépôt contient le code source, les tests et la documentation technique de Facility Defense.

- Jeu en ligne : https://facility-defense.dimitri-kara-dk.chatgpt.site
- Version publiée : V6.7.0
- Dernière fonctionnalité majeure : renforts ennemis par hélicoptère 3D sur le toit

## Dossiers principaux

- `app/` : interface et écran du jeu
- `lib/facility/` : simulation, IA, portes, escaliers, ascenseurs, rendu 2D/3D et hélicoptère
- `tests/` : tests de régression et scénarios de jeu
- `docs/` : documentation technique
- `scripts/` : outils de build et de vérification

Les captures QA volumineuses et les fichiers internes de déploiement ne sont pas inclus dans ce dépôt public.
